# Viajes Aventura

Proyecto académico TI3021 - Programación Orientada a Objeto Seguro.

## Estructura

- `docs/`: documentación, requerimientos y modelos.
- `src/presentation/`: interfaz con el usuario.
- `src/business/`: lógica de negocio.
- `src/persistence/`: conexión y acceso a datos.
- `tests/`: pruebas.

## Preparación

1. Instalar Python 3.
2. Crear un entorno virtual: `python -m venv .venv`
3. Activar el entorno.
4. Instalar dependencias: `python -m pip install -r requirements.txt`
5. Ejecutar: `python src/main.py`

La implementación inicial de persistencia está prevista con SQLite. MySQL se incorporará posteriormente.

## Flujo Git

No realizar push directo a `main`. Trabajar en ramas y abrir Pull Requests para revisión.
