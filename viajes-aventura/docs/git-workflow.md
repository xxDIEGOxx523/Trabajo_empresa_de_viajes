# Flujo de trabajo Git

1. Crear una rama para cada tarea desde `main`.
2. Usar nombres descriptivos: `feature/VA-XX-descripcion`, `docs/VA-XX-descripcion` o `fix/VA-XX-descripcion`.
3. Realizar commits pequeños y claros.
4. Subir la rama y abrir un Pull Request hacia `main`.
5. Otro integrante revisa los cambios y solicita ajustes cuando corresponda.
6. Integrar el Pull Request después de su aprobación.

No realizar `push` directo a `main`.
